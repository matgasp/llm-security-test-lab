# Security Policy

This repository is a security research and testing laboratory. Test payloads are designed for isolated development environments.

Do not point the automated scanners at systems you do not own or do not have explicit authorization to test.

Do not commit real secrets, production credentials, customer data, or live exfiltration endpoints.

Report repository vulnerabilities through a private GitHub Security Advisory when enabled for the repository.

Repository maintainers should enable branch protection, GitHub secret scanning, and push protection when those features are available. CodeQL, dependency review, dependency auditing, and Dependabot configuration are version-controlled in this repository.
